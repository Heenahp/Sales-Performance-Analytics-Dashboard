# Power BI Sales Dashboard

## Overview
This project recreates the same sales dataset from my Excel Sales Dashboard project in Power BI, to demonstrate proficiency in both Excel and Power BI for the same business analysis — including Power Query for data transformation and DAX for calculated metrics.

The dashboard provides a clear view of key business metrics and helps understand sales and profit performance across products, categories, regions, and customer segments.

## Dataset
Data used: [apna source likho — Kaggle/practice dataset/self-generated] — same sales dataset as used in the Excel Sales Dashboard project (Region, Category, Segment level sales and profit data).

## Key Metrics
- Total Sales
- Total Profit
- Total Orders
- Average Order Value

## Dashboard Features
- Sales analysis by product
- Profit analysis by category
- Top 10 products by sales
- Interactive filters for Region, Category, and Segment
- KPI cards for quick performance tracking

## Tools Used
- Power BI
- Power Query (data cleaning and transformation)
- DAX: Created basic measures for Total Sales, Total Profit, Total Orders, Total Quantity, and Average Sales
- Data Visualization

### Key Insights
- South region led in sales, followed closely by North; Technology delivered the highest profit contribution (~₹10M) among all categories, even though it wasn't necessarily the single highest revenue category — showing profit isn't purely volume-driven.
- Office Supplies had the lowest profit contribution (~₹2M) of all three categories, indicating a possible margin or discounting issue worth investigating.
- Corporate and Consumer segments contributed almost equally to total sales, while Home Office lagged significantly — a potential growth opportunity.
- Monitor, Mouse, Printer, Laptop, and Keyboard dominated the Top 10 products list (each contributing ₹12–14M in sales), reinforcing Technology's overall profit lead.
- Total business performance: ₹16M profit generated from 22K units across 3K orders, at an average sale value of ₹33.18K.

## Project Purpose
The main purpose of this project is to transform raw sales data into an interactive dashboard that provides useful business insights and supports data-driven decision-making — and to demonstrate the same analysis rebuilt across two different tools (Excel and Power BI).
