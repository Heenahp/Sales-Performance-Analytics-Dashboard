Power BI Sales Dashboard
Overview

This project is a Power BI Sales Dashboard created to analyze sales performance and business trends.

The dashboard provides a clear view of key business metrics and helps understand sales and profit performance across products, categories, regions, and customer segments.

Key Metrics
Total Sales
Total Profit
Total Orders
Average Order Value
Dashboard Features
Sales analysis by product
Profit analysis by category
Top 10 products by sales
Interactive filters for Region, Category, and Segment
KPI cards for quick performance tracking
Tools Used
Power BI
Power Query
DAX
Data Visualization
Project Purpose

The main purpose of this project is to transform raw sales data into an interactive dashboard that provides useful business insights and supports data-driven decision-making.
